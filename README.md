# Google Keep Clone

A Google Keep-inspired note-taking app built with React, Vite, JavaScript, JSX, and CSS. This project includes note creation, editing, deletion, localStorage persistence, dark mode, responsive layout, a mobile sidebar, and a modal note preview.


## Live Demo

gkeep-clone-vusim.netlify.app

## Features

- Create notes with a title and content
- Edit existing notes
- Delete notes with undo support
- Save notes in browser localStorage
- Reload notes after refreshing the page
- Responsive layout for desktop, tablet, and mobile
- Dark and light mode toggle
- Mobile-friendly hamburger sidebar menu
- Collapsible note composer
- Modal view when a note is clicked

## Tech Stack

- React
- Vite
- JavaScript
- JSX
- CSS

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the app locally

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173/
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview production build

```bash
npm run preview
```

## Notes

- Notes are saved in browser localStorage, so they persist between refreshes.
- The app is designed to be lightweight and simple, while keeping the Google Keep layout and interactions in mind.
- The project was built as a React assignment and follows a component-based structure.
